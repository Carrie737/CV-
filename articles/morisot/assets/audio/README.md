《纸间微光 · Gallery Reverie》是为此作品集编写的原创合成音乐，使用柔和的数字钢琴声、低音与稀疏的氛围和声，无人声、鼓点或第三方采样。它不是历史录音，也不代表莫里索使用过的音乐。

64 BPM，D 小调，Dm9 / Bbmaj9 / Fmaj9 / Cadd9 的缓慢和声，16 小节、60 秒循环。反射尾音延续至循环起点。音频为本地 PCM WAV（24 kHz、16 bit、立体声），无需外部音乐服务或网络授权。

同目录的 render-gallery-music.cjs 保存完整曲谱与声音合成程序，可在项目根目录用 Node.js 重新生成：

```powershell
node articles/morisot/assets/audio/render-gallery-music.cjs
```

网站默认关闭声音，仅在访客点击音乐按钮后加载并播放；音量默认 55%，可以调整或关闭。
